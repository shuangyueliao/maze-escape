# Maze Escape

Free single-file HTML5 maze puzzle game. Escape procedurally generated
perfect mazes (recursive backtracker) before the timer runs out, collect
3 hidden stars for a PERFECT escape, and brave the optional fog mode.
One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/maze-escape/

- 3 maze sizes: 11×11 (60s), 17×17 (150s), 25×25 (300s)
- Fog mode with ~3-tile vision, minimap with explored footprints
- Keyboard (arrows / WASD) + touch (swipe / on-screen D-pad)
- Procedural stone-wall textures and WebAudio sounds, no dependencies
- Best times saved per size locally
